# Distribution assets

Copy-paste content to distribute the OCR Accuracy Benchmark 2026 across dev communities. Each piece is a DISTINCT angle (not a republish) so they do not compete with each other or with the canonical blog, and each carries a dofollow link back to docsapi.co.

**Canonical asset being distributed:** https://docsapi.co/resources/blogs/ocr-accuracy-benchmark-2026

| File | Platform | Angle | Ranks for |
|---|---|---|---|
| `devto-ocr-benchmark.md` | Dev.to | Data reveal, "what surprised me" | "ocr benchmark", "best ocr engine", "paddleocr vs tesseract" |
| `hashnode-benchmark-your-ocr.md` | Hashnode | How-to / methodology | "how to benchmark ocr", "choose ocr tool", "test ocr accuracy" |
| `launch-snippets.md` | HN / Reddit / LinkedIn | One-paragraph hooks | attention + links, not search |

## Suggested cadence (one per week, do not blast all at once)

1. **Week 1:** publish the Dev.to post. Reply to every comment.
2. **Week 2:** publish the Hashnode how-to.
3. **Week 3:** Show HN (weekday morning US Eastern) + one Reddit sub.
4. **Week 4:** LinkedIn founder post + repurpose top comment questions into a follow-up.

Spacing them out means each gets its own attention window and the links land over a month instead of one spike Google discounts.

## The rules (do not skip)

- No em or en dashes anywhere. Sound human.
- Always disclose you build one of the tools tested. The honesty is what makes it work and is the whole Feelings/trust play.
- Actually sit in the comments. These earn links and brand mentions through engagement, not the post alone.
- Read each community's self-promotion rules first. Lead with data, not the pitch.

- **Convenience:** found by developers actively picking an OCR tool, the bucket already producing our only non-brand click.
- **Solutions:** every dofollow link builds the authority that lifts 77% of buried pain-query demand off page 8. This is the linchpin from Test 1.
