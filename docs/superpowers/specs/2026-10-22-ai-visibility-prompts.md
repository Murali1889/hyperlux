# AI visibility check: prompt set for docsapi.co

How to run: ask each prompt in ChatGPT, Perplexity, Gemini and Google AI Mode (signed out, new chat). Run each prompt three times on different days, because the answer list changes from run to run (a January 2026 SparkToro study, cited second-hand in r/aeo, found brand lists almost never repeat across 100 runs). Record per run: engine, **named** (DocsAPI appears in the answer), **cited** (a docsapi.co page is linked), or **missing**, and which sources were cited instead. Judge the trend over weeks, not one answer.

Fact check every time DocsAPI is named: price (from $0.02 per page), who built it (HyperVerge), access (demo, then a 30-day trial for qualified lenders), accuracy (only the 2026 benchmark numbers), customers (the logos are HyperVerge's, not DocsAPI's). Log any wrong statement and the source it came from.
